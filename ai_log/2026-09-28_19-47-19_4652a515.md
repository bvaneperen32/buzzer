## What it adds

Today every question is text only. T8 adds three uses for images:
- **Prompt images:** a picture shown with the question, on any question type.
- **Answer-option images:** multiple-choice and multi-select options can be pictures, with or without a caption.
- **An image for T7's canvas question:** T7's Spot It type will use one, but T7 builds the question type itself.

All images are stored inside the MySQL database, not as files on disk.

## Where images live

- **A library per game.** Each game has its own image library, so a picture can be reused across that game's questions. Anyone allowed to edit the game can manage its library.
- **Questions point to images, they don't contain them.** A question stores an image's id number in its existing settings (`config`). Only the new `images` table changes the database.
