## How the frontend routes are structured

Routing happens at two levels. At the URL level, the path prefix picks which app you're in. Inside each app, React Router picks the page.

### Level 1: which app (the path prefix)

**Production** ([nginx config](nginx/nginx.dev.conf)): one origin, split by prefix.
```
/             → redirects to /player/
/host/*       → host build     (unknown paths fall back to /host/index.html)
/player/*     → player build   (same)
/admin/*      → admin build    (same)
/api/*        → FastAPI
/socket.io/*  → FastAPI (WebSocket)
```

**Dev:** there are no prefixes. Each app runs its own Vite server on its own port with `base: '/'`, and forwards `/api` (and `/socket.io` for host and player) to :8000.

Each app uses Vite's `base` setting plus `basename={import.meta.env.BASE_URL}` on the router. That's why routes in the code are written without a prefix: `/home`, not `/host/home`.
