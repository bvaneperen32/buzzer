## Can you hand-write the JSON and use downloaded images?

Yes, with one limitation: **the JSON can't point to an image file.** Each image has to sit inside the file as base64 text in the `data` field. So "questions in JSON + a folder of downloaded images" needs a small packing script that reads the folder, encodes each image, and writes the finished bundle. That script would be roughly 50–100 lines with no drawing code, nothing like Dexter's 1,160.

Downloaded images are handled well:
- The import accepts **PNG, JPEG, WebP and GIF**, up to 10 MiB each (`backend/app/services/image_service.py:110`).
- Every imported image goes through the same processing as a UI upload (`process_image`, line 480). It gets shrunk to at most 1,600 px on its longest side and has its EXIF metadata stripped. Raw photos from the internet are fine.
