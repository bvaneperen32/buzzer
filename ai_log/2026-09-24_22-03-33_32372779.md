**In Docker** (`docker compose up`, from [docker-compose.yml](docker-compose.yml)):

| Service | What it is | Port on your machine |
|---|---|---|
| `nginx` | Web server and reverse proxy (it forwards requests to the backend) | **8080** → container port 80 |
| `backend` | FastAPI + socket.io, run by uvicorn with `--reload` | **8000** |
| `mysql` | MySQL 8, the permanent database | 3306 |
| `redis` | Redis 7, the live game state | none (only reachable inside Docker) |

- **nginx doesn't build the frontends.** It only serves folders that already exist on your computer: `frontend/host/dist`, `frontend/player/dist` and `frontend/admin/dist`, mounted read-only.
